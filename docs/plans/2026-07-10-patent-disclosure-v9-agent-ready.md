# 可微控制参数整定专利交底书 V9 正式化设计

## 目标

以 V8 技术交底书为技术基线，生成可直接交给专利代理人的正式版本。保留已经由项目代码和实验日志支持的技术事实，修正公式、术语和实施例中的不一致，并重新组织保护层级与 Word 排版。

## 内容调整

1. 现有技术采用代理人易复核的四段式：公开材料、公开内容、与本案的区别、公开来源；公开来源保留可点击链接。
2. 核心独立保护主线限定为：工程控制器双路径复现、车辆动力学闭环展开、场景归一化损失、梯度更新与参数投影、原始硬逻辑复验、配置导出。
3. 机理模型与冻结 MLP 残差模型的组合、MLP 诊断、域随机化、噪声和抖动作为从属增强方案，避免将其写成核心方法的必需条件。
4. 修正实施例速度范围为 5、18、25、35、45、55 km/h；修正控制增量损失从第 1 个时刻起累计，并补齐公式符号、基准损失、学习率和投影集合定义。
5. 实施例先给出纯机理模型的核心闭环整定，再给出混合模型和鲁棒增强，体现核心方案不依赖 MLP。

## 版式设计

- 统一格式基线：以用户指定的《带挂卡车轨迹重生成方法》代理人正式稿为版式参考；首页固定格式优先于通用设计预设。
- 页面：A4 纵向，左右边距 31.75 mm，上下边距 25.4 mm，与参考稿一致。
- 正文：宋体 10.5 pt、1.15 倍行距、两字符首行缩进；标题使用黑体、黑色层级，与参考稿一致。
- 首页：居中大标题“专利技术交底书”、粗横线、固定 7 行信息表及其合并关系、居中的发明名称；保留“第一发明人（必填）”“其他发明人（不超过3人）”“校招/社招”“以下由交底书撰写人填写”“以下由知识产权部填写”等统一字段，不增加文件用途说明。
- 现有技术：每件文献单独小节，公开链接显示为蓝色下划线网址。
- 表格：首页信息表使用完整细线网格；技术表使用加粗表头的黑色三线表。
- 图：两张 Mermaid 技术图和一张中文实验摘要图；图注居中，避免整页空白和缩小到不可读。
- 页脚：与参考稿一致，居中显示“第 X 页”。

## 验证门槛

1. Markdown 保留 Mermaid 源码并生成 PNG 注释引用，Word 嵌入渲染后的图。
2. Word 中公开来源为真实超链接；首页信息表、标题层级、表格宽度和页码均可正常显示。
3. 使用 Word 只读导出 PDF，逐页检查无裁切、重叠、孤立标题、异常大空白和不可读图表。
4. 公式、3.5 参数表和实施例中的符号与数值保持一致；正文不含内部自检清单、仓库路径或工具说明。
